# Oran Motoru

Futbol maçları için geçmiş verilere dayalı bir tahmin sitesi.

- Kapanış oranı aynı olan geçmiş maçların ilk yarı / maç sonu sonuçlarını gösterir.
- Her gün otomatik olarak günün kuponlarını hazırlar.

**Bu bir tahmin sitesidir; hiçbir tahmin kesinlik vermez. Yasa dışı bahis suçtur. Bahis yalnızca yasal ve lisanslı kanallardan, 18 yaşından büyükler tarafından oynanabilir.**
